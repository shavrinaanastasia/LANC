# Hypotheses

- H1: interaction frame changes the distribution of dialogue PHD. Primary contrasts: competition-neutral, cooperation-neutral, competition-cooperation.
- H2: decreasing PCA rank changes neutral-dialogue PHD. Primary contrasts: every `pca_k` minus identity for k 128, 32, 8, 2, 1.
- H3: a PHD effect is not explained only by empty, short, repetitive, copied, or semantically collapsed output.
- Null H1: each Phase 1 paired mean difference is zero.
- Null H2: each Phase 2 paired mean difference is zero.

Primary outcomes are paired mean/median difference, cluster bootstrap confidence interval, sign-flip p-value, Holm correction within phase, paired standardized effect, and valid paired-block count. Secondary outcomes are an ordered Phase 2 trend and Spearman association with `log2(k)`. Identity is not coded as PCA-576 in that trend.
